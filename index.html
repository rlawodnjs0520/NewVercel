탐구 핵심 정리

1. 실수 범위 (k = R/r)

• 정수 (k = 3, 4, ...): 1바퀴 공전 시 닫히며 k개의 뾰족점 형성
• 유리수 (k = p/q): q바퀴 공전 시 닫히며 p개의 뾰족점이 교차 형성
• 무리수 (k = π, ...): 닫히지 않고 반지름 R과 |R-2r| 사이 고리 영역을 채움

2. 복소수 확장 수식 (k = a + bi)

z(θ) = (k - 1)e^(iθ) + e^(-i(k - 1)θ) = (a - 1 + bi)e^(iθ) + e^(bθ)·e^(-i(a - 1)θ)

• 순허수 (a = 0): 대칭 뾰족점 없이 바깥으로 커지는 지수 나선 형태
